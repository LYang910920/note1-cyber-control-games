\section{From a dynamical model to a learned decision rule}
A propagation model explains how a cyber state changes under intervention. Optimal control specifies which interventions are desirable. Reinforcement learning supplies a way to learn decisions through repeated interaction with a model or environment. The connection is clearest when the same states, timing, costs and constraints are carried through all three descriptions.

The first experiment in this note is a defender facing a scripted attacker. It introduces the environment and Double DQN without requiring a network-sized state vector. Later sections retain individual nodes and introduce cooperation or competition. The aggregate example, the degree-class model in the foundation note, and the node-level extensions are distinct modeling resolutions.


\subsection{The cyber-control research behind the examples}
The research context begins with dynamical security evaluation under APTs and proceeds to strategic patching, repair, backup and recovery \cite{security2017,patch2018,repair2019,backup2021}. Conflicting-opinion and rumor-refutation models supply social-network examples with competing objectives \cite{opinions2020,rumor2021}. Impulsive artificial defense, outsourcing and hybrid propaganda control motivate the explicit separation between flow actions and reset events \cite{impulse2023,outsource2024,war2024}. Awareness-dependent propaganda suppression and coupled malware--opinion control add behavior and multiple network layers \cite{awareness2025,malware2025}.

These publications motivate the physical model and strategic questions. The first DDQN exercise below is a compact sampled SIR teaching environment, not a reproduction of every cited paper. Jafar et al.'s feedback-loop study provides a particularly direct learning--control bridge: reinforcement learning estimates unknown model parameters for an MPC-based malware-control loop \cite{feedback2024}. That estimator role differs from the direct action-value learning used in the introductory DDQN. Both fit within an observation--estimation--decision--application loop when their interfaces are specified.

\section{Start from interpretable cyber dynamics}
\subsection{The aggregate model used by the first experiment}
Let $S,I,R$ be susceptible, infected and recovered/protected fractions, with $S+I+R=1$. The sampled actions select rates that are held during one decision interval:
\begin{align}
\dot S&=-\beta_{\rm eff}SI-pS+\omega R,\nonumber\\
\dot I&=\beta_{\rm eff}SI-(\gamma+c)I,\label{eq:sampled-sir}\\
\dot R&=pS+(\gamma+c)I-\omega R.\nonumber
\end{align}
Patching $p$ protects susceptible devices; cleaning $c$ recovers infected devices. Deception reduces the effective infection rate during the interval. Protection wanes at rate $\omega$. Each transition appears with opposite signs in its source and destination compartments, so mass is conserved.

The environment has five defender modes: no intervention, patch, clean, deceive and isolate. An integer mode uses unit intensity. A parameterized action additionally specifies $v\in[0,1]$. In the current aggregate environment,
\begin{equation}
p=0.30v\mathbf1_{\rm patch},\quad
c=0.25v\,s_A\mathbf1_{\rm clean},\quad
h=0.35v\mathbf1_{\rm deceive},
\end{equation}
where $s_A=0.5$ under a stealth attack and $s_A=1$ otherwise. The transmission rate is
\begin{equation}
\beta_{\rm eff}=\beta_A\max(0,1-\chi h).
\end{equation}
The attacker selects scan, exploit, lateral or stealth. Their unit-intensity rate multipliers are respectively $1.10$, $1.50$, $1.70$ and $1.20$ times $\beta_0$. The teaching defaults are $\beta_0=0.65$, $\gamma=0.05$, $\omega=0.01$ and $\chi=0.70$. They define an illustrative simulator, not an empirically fitted incident-response model.

Isolation is a reset, not an extra rate in \eqref{eq:sampled-sir}:
\begin{equation}
S^+=S^-,\qquad I^+=(1-0.40v)I^-,\qquad
R^+=R^-+0.40vI^-.
\label{eq:isolation-reset}
\end{equation}
An alternative model may use continuous isolation, but its equations and cost must then be changed together. Calling both mechanisms ``isolation'' does not make them mathematically identical.

\subsection{Costs used in the executable environment}
Let $\bar I_r$ and $\bar S_r$ be interval averages obtained from the integrated trajectory. The defender's interval reward is the negative of
\begin{align}
C_D^r={}&\Delta_r\big[10\bar I_r+0.5\bar S_r+p^2+c_{\rm cmd}^2+1.5h^2\big]
+K_D^r,\label{eq:actual-cost}
\end{align}
where $c_{\rm cmd}=0.25v\mathbf1_{\rm clean}$ is the commanded cleaning rate: the stealth reduction changes efficacy, not the charged commanded effort. When isolation is selected,
\begin{equation}
K_D^r=2v^2+2.5(I^--I^+);
\end{equation}
otherwise $K_D^r=0$. The impulse cost is charged once. It is not multiplied by the interval length or by the number of ODE substeps.

The environment also returns an attacker reward
$\Delta_r[8\bar I_r+\bar S_r-c_A]$, where the action costs are $(0.05,0.20,0.30,0.25)v_A^2$ in the listed attacker-mode order. These separate rewards are not exact negatives, so the environment is general-sum when both sides learn. The introductory DDQN experiment keeps the attacker scripted.

\subsection{Two additional model templates}
An APT model can separate compromise, detection and repair:
\begin{align}
\dot V&=-\beta VC-u_pV+\omega P, &
\dot C&=\beta VC-(\alpha+u_m)C,\nonumber\\
\dot D&=(\alpha+u_m)C-u_rD, &
\dot P&=u_pV+u_rD-\omega P.\label{eq:apt}
\end{align}
Here $V,C,D,P$ denote vulnerable, covertly compromised, detected and protected states. Monitoring $u_m$ and remediation $u_r$ operate on different transitions. This template explains how to adapt the state and action mapping; it is not the three-state first experiment with renamed labels.

A misinformation model can instead track unaware users $U$, misinformation spreaders $M$, counter-message spreaders $C$ and inactive users $F$:
\begin{align}
\dot U&=-\beta_mUM-\beta_cUC+\delta F, &
\dot M&=\beta_mUM-\kappa MC-\eta_mM,\nonumber\\
\dot C&=\beta_cUC+\kappa MC-\eta_cC, &
\dot F&=\eta_mM+\eta_cC-\delta F.
\end{align}
A counter-messaging action might increase $\beta_c$ or $\kappa$. A sudden campaign may instead define a reset. The learning environment should inherit the selected mechanism exactly.

\section{Timing gives the environment its meaning}
\subsection{Flow actions, modes, intensities and impulses}
A real-valued action is not the same as continuous-time feedback. An agent may select a real number only every hour and hold it constant between decisions. A discrete mode may choose which vector field operates without changing the state instantaneously. A mode--intensity pair $(m,v)$ is a parameterized action; it becomes impulsive only when its map includes a reset.

For zero-order hold,
\begin{equation}
u(t)=\Gamma(a_r),\qquad t\in[t_r,t_{r+1}).
\end{equation}
With a reset, a complete transition is
\begin{equation}
x_r^+=G(x_r^-,a_r),\qquad
x_{r+1}^-=\varphi_{\Delta_r}(x_r^+,\Gamma(a_r)),
\label{eq:transition}
\end{equation}
where $\varphi$ is the ODE flow. Without an impulse, $G$ is the identity. If a physical event occurs inside the interval, integration must stop at that event, apply its reset and resume before the next policy observation.

In \texttt{SampledFlowImpulseEnv.step}, the order is pre-jump observation, joint action decoding, optional isolation reset, held-rate ODE integration and interval reward. The default $\Delta=1$ and ten RK4 substeps describe two different grids: one decision interval contains ten numerical integration steps, but contributes only one replay transition. More substeps improve numerical accuracy; more decision epochs change the control problem.

\subsection{Use a state that contains the needed information}
The current observation is
\begin{equation}
s_r=[S_r,I_r,R_r,r/K].
\label{eq:actual-observation}
\end{equation}
The fourth component is decision phase. It matters because the horizon is finite and the scripted attacker changes mode according to the decision index. The script uses scan for indices below 20, exploit from 20 through 59, and lateral movement thereafter. The default 30-decision example therefore encounters the first two regimes.

For a fixed horizon and known script, phase supplies that timing information. A model with a remaining budget, a hidden attacker mode or delays may require additional state. A partial observation is not automatically Markov. A history window, recurrent state or estimator is a possible approximation to missing information, and should be assessed as such rather than assumed to restore the Markov property exactly.

\subsection{Preserve the continuous objective in the reward}
For an undiscounted finite-horizon cost, the exact interval reward is
\begin{equation}
r_r=-K_r-\int_{t_r}^{t_{r+1}}L(x(t),u(t),t)\dd t.
\end{equation}
Include $-\Phi(x(T))$ once at termination, or equivalently use it as the terminal value. With $\gamma_d=1$, maximizing the sum of these rewards is equivalent to minimizing the stated sampled-control objective. Setting $\gamma_d$ merely ``close to one'' generally changes that objective.

For a continuously discounted cost with rate $\rho\ge0$, a relative-time Bellman formulation uses
\begin{align}
r_r&=-K_r-\int_0^{\Delta_r}e^{-\rho s}L(x(t_r+s),u(t_r+s),t_r+s)\dd s,\nonumber\\
\gamma_r&=e^{-\rho\Delta_r}.
\label{eq:discount}
\end{align}
The products of interval discounts then produce the absolute factor $e^{-\rho t}$. Discounting only the next value while leaving the within-interval cost undiscounted is an approximation when $\rho>0$. A variable interval must therefore affect reward integration and discounting consistently.

The environment approximates interval averages using composite Simpson quadrature for an even number of RK4 substeps, and trapezoidal quadrature otherwise. This is more accurate than charging damage only at the interval endpoint. The introductory DDQN uses $\gamma_d=1$, matching its reported undiscounted finite-episode cost.

\section{The classical optimal-control connection}
\subsection{PMP supplies an open-loop benchmark}
For $\dot x=f(x,u,t)$, $x(0)=x_0$ and cost
$J=\Phi(x(T))+\int_0^T L(x,u,t)\dd t$, define $H=L+\lambda^\top f$.
Normal PMP conditions are
\begin{equation}
\dot x=f,\qquad \dot\lambda=-H_x,\qquad
\lambda(T)=\Phi_x(x(T)),\qquad
u(t)\in\argmin_{v\in U}H(x(t),v,\lambda(t),t).
\end{equation}
The state starts at $0$ and the costate at $T$. The forward--backward sweep iterates those equations with a control update \cite{pontryagin,lenhart}. It returns a schedule for the specified initial state and parameters, subject to numerical convergence and the necessary-versus-sufficient distinction.

For \eqref{eq:patching-reference} below, use both patching and cleaning:
\begin{align}
\dot S&=-\beta SI-u_pS+\omega R,\nonumber\\
\dot I&=\beta SI-(\gamma+u_c)I,\label{eq:patching-reference}\\
\dot R&=u_pS+(\gamma+u_c)I-\omega R.\nonumber
\end{align}
With $L=qI+(b_pu_p^2+b_cu_c^2)/2$ and terminal cost $q_TI(T)$,
\begin{align}
\dot\lambda_S&=\beta I(\lambda_S-\lambda_I)+u_p(\lambda_S-\lambda_R),\nonumber\\
\dot\lambda_I&=-q+\beta S(\lambda_S-\lambda_I)
 +(\gamma+u_c)(\lambda_I-\lambda_R),\nonumber\\
\dot\lambda_R&=\omega(\lambda_R-\lambda_S),\qquad
\lambda(T)=(0,q_T,0)^\top.
\end{align}
The bounded control updates are
\begin{equation}
u_p=\clip\left(\frac{S(\lambda_S-\lambda_R)}{b_p},0,\bar u_p\right),\qquad
u_c=\clip\left(\frac{I(\lambda_I-\lambda_R)}{b_c},0,\bar u_c\right).
\end{equation}
These equations show exactly which mechanism a demonstration control encodes. An impulse additionally changes costates through
$\lambda^-=G_x^\top\lambda^++K_x$; it cannot be treated as an ordinary flow update without changing the problem.

\subsection{What changes when learning is used?}
PMP describes a continuous-time trajectory problem. A learned policy $a_r=\pi(s_r)$ describes a sampled feedback problem. Choosing a decision grid, restricting action modes, adding measurement noise or using a different objective may change the admissible problem. Therefore a cost comparison with an open-loop schedule should identify whether it measures matching-model optimization, feedback adaptation, robustness to mismatch, or a different operational action set.

A receding-horizon controller also reacts to observations by repeatedly solving a model-based problem. Feedback is not exclusive to RL. When feedback adaptation is the claimed benefit, a meaningful comparison may include a suitably designed feedback or MPC baseline as well as open-loop FBSM.

\subsection{Three useful ways to reuse theory}
Classical control can supply a baseline, demonstrations, or a residual-based learning objective. These uses are different. A reward-based learner uses the simulator and its objective; it does not solve the costate boundary-value problem merely because PMP was derived elsewhere. A demonstration-initialized actor uses additional teacher information. A PMP-informed neural method explicitly penalizes state, costate, boundary and constrained Hamiltonian conditions; Note 2 develops that formulation.

A constructive warm-start workflow generates control demonstrations over several initial states, maps them to the learner's actual admissible actions, trains the actor to imitate them, and then evaluates any subsequent reward-based improvement. Teacher information, approximation in the action map, and total training effort remain part of the method description.

\section{Value functions, Bellman equations and Double DQN}
\subsection{What is learned?}
For a policy $\pi$, the action value $Q^\pi(s,a)$ is the expected future discounted reward after taking $a$ at $s$ and then following $\pi$. A finite-horizon value also depends on remaining time, either explicitly or through a phase component in $s$ \cite{sutton}. For a nonterminal transition,
\begin{equation}
Q^*(s,a)=\E\left[r+\gamma_d\max_{a'}Q^*(s',a')\mid s,a\right].
\end{equation}
At a true terminal state with terminal costs already included in the reward, there is no further value to bootstrap. For sampled transitions with terminal flag $d\in\{0,1\}$,
\begin{equation}
y=r+\gamma_d(1-d)\max_{a'}Q^-(s',a').
\end{equation}
The mask must be consistent with the episode definition. An artificial training interruption is not necessarily a terminal state of the physical decision problem.

\subsection{Double DQN separates selection and evaluation}
DQN approximates the action values by a neural network \cite{mnih}. Double DQN uses the online network to select the next action and a target network to evaluate it \cite{ddqn}:
\begin{equation}
a'=\argmax_bQ_\theta(s',b),\qquad
y=r+\gamma_d(1-d)Q_{\theta^-}(s',a').
\label{eq:ddqn-target}
\end{equation}
The online network is fitted to $y$ using replayed transitions. The implementation uses a smooth-L1 loss, a form of Huber loss, and periodically copies the online parameters to the target network. The target is computed without tracking gradients.

\begin{lstlisting}[caption={The learning update in mathematical order}]
# states, actions, rewards, next_states, terminals come from replay.
predicted = q(states).gather(1, actions)
with torch.no_grad():
    next_actions = q(next_states).argmax(1, keepdim=True)
    next_values = target(next_states).gather(1, next_actions)
    expected = rewards + gamma * (1.0 - terminals) * next_values
loss = torch.nn.functional.smooth_l1_loss(predicted, expected)
optimizer.zero_grad()
loss.backward()
torch.nn.utils.clip_grad_norm_(q.parameters(), 5.0)
optimizer.step()
\end{lstlisting}

Replay contains $(s,a,r,s',d)$ for decision transitions. Random minibatches reuse previous interactions; they are not new environment interactions. The $\epsilon$-greedy behavior rule explores with probability $\epsilon$ and otherwise chooses the largest online Q value. Greedy evaluation freezes the network and disables exploratory action sampling.

\subsection{Read the actual training configuration}
The introductory network takes the four entries in \eqref{eq:actual-observation}, has two hidden layers of width 32, and produces five Q values. These outputs are action values, not probabilities. The example uses Adam, a target update every 64 decision steps, and a batch size of $\min(32,K)$. Replay stores reward divided by ten to moderate Q magnitudes; reported returns and costs use the original reward units. Uniform positive reward scaling leaves the exact maximizing policy unchanged, while it can affect numerical training.

\texttt{ddqn.train} randomizes initial infection/protection fractions. Validation uses a separate seed. \texttt{cli.run\_example} creates an untrained network with the same seed, width and depth as the training initialization, and freezes it. The final comparison then evaluates both networks and the five fixed-action policies on the same held-out initial conditions.

\begin{lstlisting}[caption={A small training call using the repository API}]
from cybergames.configs import DDQNConfig
from cybergames.ddqn import train, evaluate

cfg = DDQNConfig(
    episodes=20, horizon=30, eval_horizon=30,
    hidden=32, batch_size=32, gamma=1.0,
    log_every=5, device="cpu", seed=0
)
q_network, history = train(cfg)
score = evaluate(q_network, episodes=5, seed=10000, horizon=30)
print(score)
\end{lstlisting}
This shorter call demonstrates the interface, not a recommended performance budget. The normal CLI also generates paired baselines and figures.

\subsection{Termination is part of the objective}
The aggregate environment ends when its decision horizon is reached, when $I<10^{-5}$, or when $I>0.95$. Therefore its reported cost is the cost over that terminated episode. An application requiring continued maintenance after containment, or a penalty for catastrophic compromise, should encode that continuation/terminal cost explicitly. Otherwise stopping can remove future costs and change which policy looks attractive. Policy comparisons must share the same termination rule.

\section{Read the learning result as a control result}
\subsection{The default output files}
The \texttt{results/} directory contains \texttt{learning.png}, \texttt{infection.png}, \texttt{actions.png}, \texttt{training.csv}, \texttt{comparison.csv}, and \texttt{trajectories.csv}. Learning curves use validation return. The infection and action plots show the first held-out initial condition. The comparison table retains every evaluated case, so the printed averages can be traced back to paired outcomes.

The five fixed policies repeatedly choose no intervention, patch, clean, deceive or isolate. They are not fitted to the test cases. The comparison table uses cost, where lower is better; the validation curve uses reward, where higher is better. More intervention can reduce infected time while increasing total cost. Inspect both rather than ranking policies by infection alone.

\subsection{Separate three learning questions}
Parameter changes show that optimization occurred. Changed executed actions show that the policy changed. Improved held-out cost shows that the change was useful under the specified objective. These are three different statements. A decreasing temporal-difference loss is not sufficient evidence for the third.

A strong constant policy can be a genuine feature of a simple simulator. Retaining it helps students see when adaptive action selection matters. To study adaptive allocation, introduce a motivated source of variation---heterogeneous node risks, shared resources, changing observations or competing actions---and retain informative baselines under the resulting model.

For a new research variant, begin with a bounded small experiment. Compare an untrained policy, the trained policy, fixed actions and an appropriate rule/control-based method on common cases. Expand network size or interaction count after the action mapping and learning behavior are understood. Report uncertainty over independent training seeds separately from variation over test cases.

\subsection{Keep comparisons physically matched}
Common initial states, disturbances, graph samples, budgets, action bounds and evaluation horizons should be used where pairing is meaningful. When two methods receive different observations or training information, describe those differences. A teacher-initialized policy may have a useful learning advantage, but that is a different mechanism from extra information being available only at deployment.

Changing the number of episodes changes learning effort. Changing the horizon, decision interval or action costs changes the control problem. Changing numerical substeps changes integration accuracy. These changes answer different questions and should not be pooled into a single unnamed improvement.

\section{Continuous actions and actor--critic methods}
\subsection{Why an actor and a critic?}
A Q network with one output per discrete action is natural for five modes. A large continuous action vector cannot be enumerated so easily. An actor represents the policy, while a critic estimates its value or action value. A bounded scalar effort can be parameterized by
\begin{equation}
u=\underline u+(\bar u-\underline u)\sigma(z),\qquad
\sigma(z)=\frac{1}{1+e^{-z}}.
\end{equation}
With finite logits this lies strictly inside the interval; exact boundary actions require another representation or an explicit limiting/projection interpretation. Multiple independent sigmoid outputs do not enforce a shared budget.

\subsection{PPO and advantage estimation}
For a stochastic actor, define the likelihood ratio
\begin{equation}
\rho_r(\theta)=\frac{\pi_\theta(a_r\mid o_r)}{\pi_{\rm old}(a_r\mid o_r)}.
\end{equation}
PPO maximizes a clipped surrogate \cite{ppo}:
\begin{equation}
\E\left[\min\left(\rho_r\widehat A_r,
\clip(\rho_r,1-\epsilon,1+\epsilon)\widehat A_r\right)\right].
\end{equation}
The advantage estimates whether an action performed better than the critic expected. A generalized advantage recursion uses
\begin{align}
\delta_r&=r_r+\gamma_d(1-d_r)V(s_{r+1})-V(s_r),\nonumber\\
\widehat A_r&=\delta_r+\gamma_d\lambda_{\rm GAE}(1-d_r)\widehat A_{r+1}.
\end{align}
A rollout cut before a true terminal state needs the appropriate bootstrap value. In recurrent or partially observed settings, the actor state and stored information must also be consistent.

For a mode--intensity policy, specify its joint probability, for example
$\pi(m,v\mid o)=\pi_m(m\mid o)\pi_v(v\mid o,m)$. The policy ratio must correspond to the distribution that actually generated the executed action. Clipping or repairing an action after sampling without accounting for its changed distribution can invalidate that ratio.

\subsection{Deterministic actors and entropy-regularized actors}
DDPG uses a deterministic actor with an action-value critic; SAC uses a stochastic actor and an entropy-regularized objective \cite{ddpg,sac}. The latter balances expected reward against policy entropy. These choices affect the optimized criterion and exploration, so an entropy term should not be confused with a physical intervention cost.

These methods provide background and extension routes. The primary packaged learning implementations are DDQN, a compact centralized-critic example, community MAPPO and adversarial self-play. The default command does not silently run every algorithm discussed in the theory.

\section{Several agents: cooperation, competition and equilibrium}
\subsection{A Markov game retains separate rewards}
A Markov game consists of a state space, one action/observation space per player, a joint-action transition law, and player-specific rewards \cite{littman}. In a cooperative problem, agents optimize a shared objective or a stated team criterion. In a zero-sum problem, one player's payoff is the negative of the other's. In a general-sum problem, each has its own tradeoffs.

A payoff-maximizing feedback Nash profile satisfies
\begin{equation}
V_i^{\pi_i^*,\pi_{-i}^*}(s)\ge
V_i^{\pi_i,\pi_{-i}^*}(s)
\end{equation}
for every admissible unilateral policy and every relevant state/time in the stated solution concept. An open-loop Nash schedule instead concerns unilateral time functions for a fixed initial condition. A Stackelberg problem additionally specifies commitment and response. These are distinct strategic questions \cite{basar}.

\subsection{Centralized training and decentralized execution}
During training, a critic may use the full simulator state and joint actions,
\begin{equation}
Q_i(s,a_1,\ldots,a_N).
\end{equation}
At execution, the actor uses only its declared observation,
$\pi_i(a_i\mid o_i)$. This is centralized training with decentralized execution (CTDE) \cite{maddpg}. It can improve value estimation but does not eliminate every source of nonstationarity. Global information must not leak into a supposedly local actor at evaluation.

MAPPO applies PPO-style updates to multi-agent actors, often using a centralized value critic \cite{mappo}. The cooperative community-control implementation and an adversarial attacker--defender experiment should be introduced separately. A shared-reward cooperative success is not evidence of an adversarial equilibrium.

\subsection{Train responses, then examine interaction}
A useful progression learns a defender against specified opponents, learns a response with the defender frozen, and then explores alternating or population-based training. Opponent pools expose a policy to more than the latest opponent. Evaluate a cross-play matrix with frozen row and column policies rather than relying only on the self-play training reward.

For a learned profile, the true unilateral improvement is
\begin{equation}
\Delta_i=\sup_{\pi_i}V_i^{\pi_i,\pi_{-i}^*}-V_i^{\pi_i^*,\pi_{-i}^*}.
\end{equation}
A retrained response or a finite pool finds an attainable improvement, hence a lower bound on $\Delta_i$. A large improvement demonstrates exploitability. A small observed improvement is evidence about the tested response class and optimization budget; it is not a certified global upper bound on exploitability. Independent player residuals, cross-play and matched unilateral-response searches provide complementary information.

\subsection{Parameterized and impulsive game actions}
An attacker and defender may each choose a mode and intensity. Specify whether their actions are simultaneous, whether either observes the other's current action, and how joint resets are ordered. Two noncommuting reset maps produce different outcomes under different orders. A simultaneous model needs an explicitly defined joint reset, not an incidental order in Python.

Between events, the joint mode can select a flow field
$\dot x=f_{m_A,m_D}(x,v_A,v_D,t)$. At a genuine impulse, apply $G(x,a_A,a_D)$ and the relevant instantaneous payoffs. Cooperative, zero-sum and general-sum reward definitions remain unchanged by the fact that the state has a jump.

\section{Retain network structure and operational constraints}
\subsection{Node-level dynamics and the incoming matrix}
Let $S_i,I_i,P_i$ denote node-level state probabilities. An illustrative heterogeneous SIPS structure is
\begin{align}
\dot S_i&=-s_iS_i\sum_jA_{ij}b_jI_j-e_i^pu_i^pS_i+\omega_iP_i,\nonumber\\
\dot I_i&=s_iS_i\sum_jA_{ij}b_jI_j-(\gamma_i+e_i^cu_i^c)I_i,\label{eq:node-sips}\\
\dot P_i&=e_i^pu_i^pS_i+(\gamma_i+e_i^cu_i^c)I_i-\omega_iP_i.\nonumber
\end{align}
Here $s_i$ includes the acquisition-rate scale, $b_j$ is relative infectivity, and $e_i^p,e_i^c$ are intervention efficacies. The shared library supplies node-SIPS dynamics and sparse pressure operations; the learning environment defines which nodes or communities receive each action.

For external graphs, use a fixed node order and transpose the directed NetworkX adjacency to obtain $A_{ij}=j\to i$. Keep the same order for state arrays, community labels, risks and observations. A small example is
\begin{lstlisting}
import networkx as nx
G = nx.read_graphml("data/network.graphml")
nodes = list(G.nodes())
A = nx.to_scipy_sparse_array(
    G, nodelist=nodes, weight="weight", format="csr"
).T.tocsr()
\end{lstlisting}
The listing is a matrix-construction example, not a claim that the default aggregate DDQN accepts a graph CLI option. To use it in learning, adapt \texttt{node\_env.py} and the corresponding observation/action dimensions.

\subsection{Degree aggregation remains indexed by degree}
For an undirected degree model, calculate $N_k,P(k),\bar k$ from the full graph before defining $x_k$ and $u_k$. Its pressure is $\Theta=\sum_k kP(k)x_k/\bar k$ under the uncorrelated closure. A community index, a node index and a degree class are different labels. Aggregating an observation over a community does not change the underlying state equation into a degree model.

Node-level expected infected population is $\sum_i I_i$, and infected-node time is $\int\sum_iI_i\dd t$. These quantities have interpretable population/time units. If the simulator stores binary node states, its raw infected count is integer-valued; fractional mean-field expectations and observed integer counts should be labeled accordingly.

\subsection{Enforce the resource constraint on executed actions}
A budget may limit the number of active communities, total patching effort, or simultaneous isolation events. Its interpretation determines the admissible action space. For a discrete budget, a mask or structured selection rule can prevent impossible actions. A continuous simplex or budget-constrained map can allocate shared effort. Independently clipping each control only enforces independent bounds.

The actor, replay record and evaluation must agree on the action actually executed. Recording an unconstrained proposal while executing a different budget-repaired action changes the transition associated with the recorded action. For PPO-style policies, the probability/log-probability also needs to match the executed sampling procedure.


\section{From published control models to learning experiments}
\subsection{Preserve the decision problem during the conversion}
The patch-injection, repair and backup/recovery studies give concrete strategic cyber-control settings \cite{patch2018,repair2019,backup2021}. To construct a learning environment from one of them, copy its state meanings, physical transition rates, admissible decisions and objective first. Specify what is observed at each decision time. Then approximate continuous controls by the chosen action representation and integrate the original cost over each interval.

Changing a continuous-valued control into five discrete actions restricts the policy class. Adding feedback observations expands the information pattern relative to an open-loop schedule. Either change can alter the attainable value. The comparison should state whether it measures numerical solution quality, feedback adaptation, information acquisition or a different intervention design. This makes the role of the learned policy interpretable rather than relying on the word ``learning'' alone.

\subsection{Parameter learning and MPC: an established feedback connection}
Jafar et al. combine learning-based parameter estimation and MPC for IoT malware propagation \cite{feedback2024}. Their learning component concerns unknown coefficients of the dynamical model; it should not be described as the same action-selection procedure as \texttt{ddqn.py}. The distinction is visible in the information flow:
\[
\text{observations}\ \longrightarrow\ \text{parameter update}\
\longrightarrow\ \text{predictive control}\ \longrightarrow\ \text{new observations}.
\]
A direct DDQN instead maps its observation to action values and chooses an action. A hybrid learning/control experiment can use either approach, but should expose which object is learned: parameters, a value function, an initialization, an estimator or a policy.

A useful extension exercise compares fixed-parameter MPC, parameter-updating MPC and an observation-matched learned policy. Keep the physical simulator, intervention limits and test initial states the same. Include an untrained or unupdated counterpart for the learned component. Improvement caused by updated parameters is an inference benefit that can improve decisions even when the optimizer itself is unchanged.

\subsection{Impulse decisions and hybrid propaganda competition}
Impulsive artificial defense and defense outsourcing motivate environments in which an action applies an immediate reset and incurs an event cost \cite{impulse2023,outsource2024}. Derive that reset from the chosen application; a rate adjustment held over a decision interval is a flow action. The two mechanisms have different transitions, costs and learning consequences.

The propaganda-war paper provides a degree-based two-player hybrid example \cite{war2024}. Its code separates network preprocessing, forward propagation, backward adjoints and player-specific strategy updates. To study learned feedback on that model, construct observations and action maps for both players while preserving their individual payoff definitions. Continuous effort and event intensity may be represented by different action components. Event times can remain fixed, coincide with decision times, or be selected by a policy, but the choice must be part of the environment definition.

The original forward--backward game and a new multi-agent learning formulation answer related but distinct solution questions. A cooperative MAPPO implementation is not automatically suitable for opposing objectives. Evaluate competitive policies against frozen opponents and alternative responses, and state whether the solution sought is open-loop Nash, feedback Nash, Stackelberg or a restricted-policy comparison.

\subsection{Awareness creates a state, an observation and an intervention question}
The awareness-based propaganda and coupled malware--opinion studies distinguish a propagation state from an awareness/opinion state \cite{awareness2025,malware2025}. Their interventions can affect those states through different channels. A learning adaptation should therefore decide which state is observable, whether an estimate is supplied to the policy, and whether an action modifies infection directly or changes subsequent susceptibility through awareness.

Ablating awareness changes the mechanism or information available to the controller. Freezing a learned policy changes the decision rule. Disabling an impulse changes the admissible intervention. These comparisons should be labeled separately. The same principle applies to the conflicting-opinion and rumor-refutation games: each player's benefit/cost and the population interpretation must remain intact when introducing an actor and critic \cite{opinions2020,rumor2021}.

The small node-level and multi-agent examples in this repository are teaching extensions. The papers and attributed research code supply the application-specific equations and constraints. The learning machinery here provides an explicit route to new experiments without presenting those extensions as already established results of the cited publications.

\subsection{Adapt one physical mechanism at a time}
For a new model, specify the state and units, derive the transitions, and then revise the observation, action map, reward and termination rule. Match the policy's input dimension to the observation and its output to the admissible action representation. A new cost weight changes the decision problem; a new neural width changes its approximation.

For a new impulse, define its reset and instantaneous cost before coding. For a delayed state, retain the required history and use an appropriate delay solver. For a time-varying graph, advance the graph schedule in the same physical time units as the decisions. For a partial-observation model, assess the estimator or memory policy as part of the decision method.

Changing the mathematical model also changes any PMP teacher or baseline. Update its Jacobian, costate equations and control optimizer rather than importing a schedule from an incompatible mechanism. When inference is used upstream, carry parameter uncertainty into the control comparisons instead of treating a fitted rate as known truth.

\subsection{Exercises with worked answers}
\paragraph{Impulse cost.} A reset costs 2 units and the next decision is 0.25 hours later. What is the impulse contribution to reward?\par
\emph{Answer:} $-2$, not $-0.5$. Only the running rate cost is integrated over the quarter-hour interval.

\paragraph{Terminal target.} A terminal transition has reward $-3$, discount 1 and a target network predicting future value 10. What is the correct Double DQN target?\par
\emph{Answer:} $-3$, because $(1-d)=0$. Adding 10 would bootstrap past the defined episode.

\paragraph{Learning evidence.} Network parameters change, but every greedy action remains patch. What has been demonstrated?\par
\emph{Answer:} Optimization changed the function approximation. It has not yet demonstrated a change in the executed greedy policy or an improvement over repeated patching.

\paragraph{Comparison scope.} A feedback policy beats an open-loop schedule after a new infection shock. Does that prove a better solution to the original deterministic control problem?\par
\emph{Answer:} It provides evidence of adaptation under that shock. Pure optimization superiority requires matching the original dynamics, information and admissible decisions.

\appendix
\section{Neural and numerical essentials}
An MLP composes affine maps and nonlinear activations. A Q network outputs real action values. A categorical actor transforms logits into probabilities using softmax. A continuous actor maps outputs to an admissible effort space. A critic estimates a scalar state/action value. These roles should be clear before selecting width and depth.

RK4 evaluates four slopes for each numerical step. In a sampled environment, the action is held according to the specified action map during those evaluations. A projection can remove small numerical violations of a simplex, but repeated large projections alter the dynamics. Test step refinement and conservation at the equation level before using trajectories as learning data.

A basic NumPy/PyTorch model pair should agree on state ordering and rates. Seeded initial-condition pairing improves comparisons; it does not guarantee bitwise equality across all hardware. Computation time, learning interactions and solver evaluations are different measures and should be reported separately when relevant.

\section{Connect this note to estimation and physics-informed learning}
A neural ODE represents part or all of a vector field and differentiates through integration. A PINN represents trajectories and trains using equation residuals. PIDL is a broader model-and-data learning approach \cite{neuralode,pinn}. These can estimate a mechanism before control, or produce equation-informed numerical candidates. They do not automatically choose operational actions or establish equilibrium.

A useful end-to-end chain is observation, state/parameter estimation, decision, physical application and new observation. The foundation note supplies continuous and impulsive control theory; Note 2 develops the inference and residual-learning components. Keeping their interfaces explicit makes it possible to identify whether an improvement comes from better state information, better modeling, better allocation or learned feedback.
